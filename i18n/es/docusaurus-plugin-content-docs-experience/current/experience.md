## Con qué trabajo

<CardGrid columns={2}>
<Card title="Jira en producción">

Soporte avanzado, sobre todo en Data Center y con conocimiento de Cloud: cada incidencia, sencilla o compleja, era mía hasta resolverla.

- Diagnóstico con las Troubleshooting and Support Tools de Atlassian, logs de la aplicación y del sistema, y datos recopilados de varios nodos.
- Problemas de permisos y notificaciones rastreados con Permission Helper y Notification Helper.
- Reindexación completa de la instancia cuando los problemas de consistencia o de búsqueda lo requerían.
- Reproducir las incidencias en Jira, Confluence y apps de terceros antes de sacar conclusiones.

</Card>
<Card title="Apps del Marketplace y proveedores">

Muchos problemas están en las apps que rodean a Jira, no en Jira.

- Resolución de problemas en apps como ScriptRunner, Xray y Xporter.
- Distinguir entre un problema de configuración, un problema de una app y un error del producto.
- Preparar la evidencia técnica, escalar a Atlassian Support y a los proveedores de las apps cuando el problema lo requiere, y seguir cada caso hasta que se resolvía.

</Card>
<Card title="ScriptRunner y Groovy">

Código donde la configuración se queda corta.

- Behaviours, validators, conditions, post-functions y listeners.
- Scheduled jobs, la Script Console y endpoints REST personalizados.
- Scripting administrativo: diagnóstico, comprobar el comportamiento como un usuario concreto, operaciones masivas y análisis de logs.

</Card>
<Card title="Integraciones y datos">

Conectar Jira con el resto de las herramientas.

- Webhooks entre Jira y procesos externos y herramientas de colaboración.
- APIs REST y sincronización de datos.
- Importaciones CSV, Issue Collectors y procesos de exportación programados.

</Card>
<Card title="Diseño de soluciones">

Desde el primer requisito hasta producción.

- Análisis de requisitos, prueba de concepto, pruebas, demos e iteración con el cliente.
- Elegir entre configuración, automatización, integración y código a medida.
- Configuración de Jira: esquemas, workflows, roles, permisos y SLAs, además de request types, portales y colas de Jira Service Management.

</Card>
<Card title="Assets">

Datos estructurados, trazables y consultables.

- Diseño de esquemas: object types, atributos, relaciones, estados y dependencias de datos.
- AQL y campos personalizados de Assets para seleccionar datos de forma dinámica.
- Automatización, importaciones, sincronización y reportes sobre el modelo, documentados en Confluence.

</Card>
</CardGrid>

## Dónde se juntó todo

Algunos de los proyectos detrás de esto (anonimizados, sin nombres de clientes):

- **Soporte avanzado de Atlassian.** Un entorno de Jira Data Center lleno de configuración a medida, procesos internos, integraciones y apps de terceros.
- **Diseño e implementación de una solución.** Una solución Atlassian para un cliente, desde los requisitos hasta producción, equilibrando Jira estándar, automatización y código a medida.
- **Gestión de activos y trazabilidad.** Jira y Assets trabajando juntos para que operaciones pudiera rastrear cada activo.
